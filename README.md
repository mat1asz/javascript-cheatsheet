# Parciales resueltos completos

Acá están los 3 exámenes que resolví completos y funcionando (HTML + CSS + servidor + mi script.js ya terminado). Los otros dos que hice (Cafetería y Eventos) no los tengo guardados como proyecto completo, solo las notas y bugs en la carpeta principal del cheatsheet.

## Cómo los uso

Cada carpeta es un proyecto independiente, con su propio `package.json`:

```
cd mascotas-adopcion   (o gamehub, cafeteria, eventos, o biblioteca-practica)
npm install
npm start
```

Después abro el `index.html` de esa carpeta con Live Server.

## Qué hay en cada uno

- **mascotas-adopcion** → catálogo de animales, filtro por especie, formulario de adopción
- **gamehub** → catálogo de videojuegos, filtro por plataforma + orden por calificación, favoritos
- **cafeteria** → catálogo de productos, filtro + búsqueda en notas de cata, cálculo de precio, comandas
- **eventos** → catálogo de eventos, filtro por género (con slug) + búsqueda, compra de entradas
- **biblioteca-practica** → examen que armamos para practicar de cero, préstamo de libros
